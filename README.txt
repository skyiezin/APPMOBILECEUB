Este projeto foi desenvolvido como parte de um trabalho acadêmico do curso de Análise e Desenvolvimento de Sistemas, pelo aluno ARTHUR LUIS PINHO DE LIMA FILHO, RA 72301608, para a matéria de programação para dispositivos móveis, com o objetivo de simular um aplicativo real de controle financeiro acessível, funcional e focado em usabilidade local, sem necessidade de conexão com a internet.

Funcionalidades do app: 
- Cadastro e login de usuários (dados salvos localmente)
- Entrada de salário, despesas fixas e variáveis, e meta de economia mensal
- Cálculo automático da sobra mensal
- Verificação se a meta de economia foi atingida
- Exibição dos maiores gastos de cada mês
- Relatório anual com gráfico de desempenho
- Troca de tema claro/escuro manual
- Edição de perfil (nome, telefone, endereço, senha)
- Notificações mensais para lembrar o usuário de cadastrar seus dados
- Armazenamento separado por usuário e por mês/ano
- Gráficos com dados relevantes

Tecnologias Utilizadas: 
- Kotlin
- Jetpack Compose
- DataStore Preferences (armazenamento local por usuário)
- SQLite (registro de gastos por mês)
- Android Jetpack Libraries
- Notificações locais

O projeto consta de 3 arquivos:
- AssistenteFinanceiro.APK, que contem o APK do projeto
- PrintsAppFuncional, que contém as prints do projeto em funcionamento
- SistDEVJAVACEUB/MyApplication2, que contem o código fonte do projeto

Como Rodar o APP: 

1 - Abra o projeto no android studio, que está na pasta Sist.DEVJAVA.CEUB/MyApplication2
 1.1 - Ao abrir o android studio, é só ir em file>open e selecionar a pasta do projeto
2 - Sincronizar o Gradle, clicando em "Sync Now", apos abrir o projeto
3 - Conecte um dispositivo Android via USB ou inicie um emulador, e inicie o aplicativo
 3.1 - Clicar no botão "Run" no android studio ira compilar e executar o app
4 - Certifique-se de conceder permissões, caso solicitado.
